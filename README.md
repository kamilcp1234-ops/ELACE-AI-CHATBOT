# ELACE AI Support Assistant

AI-powered customer support assistant for ELACE 3D Labs using Retrieval-Augmented Generation (RAG).

## Features

- AI-powered customer support
- Vector search
- BM25 keyword search
- Hybrid search
- Cross-encoder reranking
- Gemini AI answer generation
- FastAPI backend
- Web-based chat interface

## How It Works

The system takes a customer's question, retrieves relevant information from the knowledge base using vector search and BM25 search, combines and reranks the results, and then uses Gemini AI to generate the final answer.

## Technologies

- Python
- FastAPI
- Gemini AI
- Sentence Transformers
- BM25
- RAG
- HTML
- JavaScript
- Tailwind CSS

## Knowledge Base Documents

The `documents/` folder contains ELACE 3D Labs knowledge-base documents used by the RAG system.

These company documents are intentionally excluded from the GitHub repository using `.gitignore` and are not uploaded to GitHub.
