# File Submission and Customer Models

## Accepted file formats

ELACE accepts:
- STEP
- STL
- OBJ
- Blender files, where practical

## Preferred format

STEP is the preferred format when available.

## STL dimensions

When submitting an STL file, the customer should clearly state the exact intended dimensions of the object.

This is important because STL files can sometimes be interpreted at an unintended scale. The customer should therefore specify the required physical dimensions when sending an STL.

## Customer-supplied models

Customers may provide 3D models for printing.

ELACE can attempt to repair model issues where practical.

## Customer responsibility

If a customer-provided design contains geometry/design faults and the print fails because of those faults, ELACE does not take responsibility for the resulting failure under the stated policy.

## ELACE-designed models

If ELACE designs the model and the resulting print fails due to an ELACE design or dimensional-accuracy issue, ELACE will replace the affected part free of charge under the stated replacement policy.

## Recommended information

Customers should provide:
- 3D model/file,
- required dimensions,
- intended use,
- material,
- colour,
- quantity,
- finishing requirement,
- deadline,
where applicable.
