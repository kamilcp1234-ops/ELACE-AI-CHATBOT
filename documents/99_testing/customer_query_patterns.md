# Customer Query Patterns

## Delivery time

Customers may ask:
- How fast can you print this?
- When can I get my part?
- Can you do it today?
- How long does a 3D print take?
- Can you ship this tomorrow?
- I need this urgently.
- What is your lead time?

## Material

Customers may ask:
- Which filament is strongest?
- What plastic should I use?
- Do you have flexible filament?
- Can you print TPU?
- Do you have ABS?
- Can you use my preferred brand?
- Can you get a specific colour?

## FDM vs SLA

Customers may ask:
- Which is better, FDM or SLA?
- Which gives a smoother finish?
- Which is stronger?
- Which is better for a functional part?
- Which is better for a miniature?
- Should I use resin or filament?

## Ordering

Customers may ask:
- How do I order?
- Do I need to pay upfront?
- How much advance do I need to pay?
- When do you start printing?
- Can I cancel my order?
- Can I send my STL?

## Returns

Customers may ask:
- Can I return it?
- Can I get a refund?
- What if the print is damaged?
- What if my design is wrong?
- What if your print has the wrong dimensions?
